System Data Flow

Under the hood of VillFlow

How speech travels from your microphone directly into your active window as clean text or parsed commands.

01 / Trigger & Record
Global Key Hook
Tauri binds to low-level Windows keyboard hooks. Holding caps lock starts capture via your microphone using the Rust cpal crate.
02 / Real-time Transcribe
Speechmatics WebSocket
Audio is captured and streamed over WebSockets directly to Speechmatics for low-latency, highly accurate, multilingual transcribing.
03 / AI Formatting
Groq LLM Cleanups
The raw transcript is sent to Groq LLaMA models. It runs local instructions to clean up filler words, format bullet points, or interpret instructions in Command Mode.
04 / Keystroke Injector
Virtual Keyboard
The finalized text is injected directly into your active window cursor location using character-by-character keyboard emulation (Enigo) or clipboard paste.

Desktop Features

Built for desktop efficiency.

Why use the desktop application instead of standard voice tools?

Global Shortcut Mapping
Press your custom hotkey while working in Outlook, Notion, Docs, Discord, or Cursor to type instantly.
Floating Overlay Pill
A premium transparent status indicator overlays always-on-top so you see states (Recording, Processing) on-the-fly.
Secure Key Storage
Keys are encrypted and locked within Windows Credential Vault instead of readable text files.
Background System Tray
App minimizes to taskbar/tray immediately. Auto-starts on startup for immediate availability.
How it works

Instant workflow acceleration.

Setup VillFlow and dictate in three easy steps.

01
Run installer
Download and execute either WiX MSI or NSIS setup. The app will launch directly into the system tray.
02
Add your free keys
Enter your Speechmatics and Groq API keys in the Settings Panel. (Both offer generous free-tier tokens).
03
Hold hotkey & dictate
Hold your active global hotkey (PTT) to dictate text directly into the cursor location of any focused app.
